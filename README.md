# Fractal Bifilar Coil

A project to design and test **fractal bifilar coils**, combining fractal geometries (e.g., Hilbert, von Koch curves) with Nikola Tesla’s bifilar coil design (Patent 512340) for advanced electromagnetic applications. Aims include tunable field gradients, Planck-scale measurements, and potential quantum or dark matter experiments.

## Motivation
Inspired by Tesla’s bifilar coil for enhanced energy storage and resonance, this project explores fractal patterns to create tunable electromagnetic fields. Potential applications include:
- **Electromagnetic Resonance**: Optimizing coils for low-frequency resonance (e.g., 7.83 Hz Schumann resonance).
- **Planck-Scale Sensing**: Probing quantum or unified field theory phenomena.
- **Novel Applications**: Seismic detection of dark matter or rescaling energy paradigms (e.g., Kardashev Scale).
